Privacy Policy

Last updated: 8 November 2026

ProblemAgent (“the app”) is a private tool used only by its owner to manage the owner's own YouTube channels. This policy explains what Google user data the app accesses and how it is handled.

Data accessed

When the owner signs in with Google, the app requests these YouTube permissions:

  • youtube.upload: upload videos to the signed-in channel.
  • youtube.readonly: read channel name and ID to confirm the upload target is correct.
  • youtube.force-ssl: manage video metadata (title, description, visibility) of the channel's own videos.
  • yt-analytics.readonly: read view and engagement statistics for the channel.

How data is used

The data is used only to upload the owner's videos, verify the correct channel, and show the owner performance statistics for their own content. It is not used for advertising and is not sold.

Storage and sharing

OAuth tokens and statistics are stored only on the owner's own computer. No Google user data is transferred to, shared with, or disclosed to any third party.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored tokens and data can be deleted on request.

Amazon Selling Partner API data

For the owner's own Amazon seller account (HappySproutStore LLC / Echo Sprout Store) the tool accesses: our own product listings, orders, inventory, account performance and financial/settlement reports. No buyer personally identifiable information (names, addresses, phone numbers) is requested or stored. The data is used only to create and manage our own listings and to build internal summaries for the owner. It is stored on the owner's computer, protected in transit with TLS, never sold or shared with third parties, and deleted when no longer needed. API credentials are kept in a local, access-restricted configuration file that is excluded from version control. Security incidents involving Amazon information are reported to security@amazon.com within 24 hours of detection.

Meta (Facebook and Instagram) data

The Meta app “ProblemAgent Yayın” is used only by its owner to publish the owner's own videos (Reels) and images to the owner's own Facebook Pages and Instagram professional accounts, and to read statistics (views, reach) for that content. It does not offer Facebook Login to other people.

When someone comments on or sends a message to the owner's own Page or Instagram account, the app may read that comment or message and the sender's public username and ID in order to reply. This data is used only to answer that person, is stored only on the owner's computer, is never sold, shared or used for advertising, and is deleted when no longer needed (at most 90 days).

Main permissions used: pages_show_list, pages_read_engagement, pages_read_user_content, pages_manage_posts, pages_manage_engagement, pages_manage_metadata, read_insights, instagram_basic, instagram_content_publish, instagram_manage_comments, instagram_manage_messages, instagram_manage_insights, business_management. Access tokens are kept in an access-restricted local file excluded from version control.

Data deletion: see the data deletion instructions.
